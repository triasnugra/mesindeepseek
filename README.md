
# 🧠 Eliz-Style Crypto Analysis Engine

Mesin analisis crypto otomatis yang dibangun berdasarkan strategi **Price Action & Liquidity** dari @eliz883.

## 🎯 Filosofi Utama
1. **Market tidak bisa diprediksi, hanya bisa di-reaksi.**
2. **Monday Range** adalah kerangka utama minggu.
3. **Liquidity Sweep + Deviation + Reclaim** adalah trigger entry.
4. **Middle of the Range = No Trade Zone.**
5. **Discipline > Strategy** (Risk Management adalah segalanya).

## 🚀 Fitur
- ✅ Deteksi **Monday Range** otomatis.
- ✅ Deteksi **Liquidity Sweep** (Stop Hunt) di area High/Low.
- ✅ Deteksi **Deviation & Reclaim** (False Break).
- ✅ Peringatan **No-Trade Zone** di tengah range.
- ✅ Multi-Timeframe Analysis (HTF: Weekly/Daily, LTF: H4).
